# Informe 3 - Métodos de Strings en Python

## Descripción

Este informe contiene ejemplos prácticos de los principales métodos de strings en Python.

Cada método incluye:

- Explicación de para qué sirve
- Ejemplo básico
- Ejemplo avanzado
- Comentarios dentro del código
- Resultados esperados

El objetivo del informe es aprender cómo funcionan los métodos de cadenas de texto en Python y cómo aplicarlos en situaciones reales.
